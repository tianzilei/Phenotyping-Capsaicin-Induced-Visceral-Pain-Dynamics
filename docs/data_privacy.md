# Data handling and restricted pseudonymization

Public content is limited to code, method configurations without individual adjudications, blank schemas, synthetic fixtures, and reviewed aggregate outputs. No real individual table belongs in Git, even if names or original IDs have been removed. Aggregate counts are retained as reported; no cell-suppression rule or formal disclosure-risk certification is claimed.

`scripts/deidentify_data.py` creates a fresh directory outside every detected Git checkout. Its baseline policy selects known structured fields only. It removes `ACQ_CNP_files` and `Additional_symptoms`; other names, contact information, dates, file links and free-text columns cannot be selected. Unexpected columns are omitted by the baseline allowlist; linked-table policies require explicit selected and identifier columns. Filename/path-like values in selected columns are rejected.

The exporter assigns a cryptographically random 96-bit ID, `P_` followed by 24 hexadecimal characters. It does not derive IDs from a name, original identifier, row number or public hash. All linked files in one export share a mapping; confirmed identity aliases may be supplied as private JSON. The tool does not infer aliases or merge records. Unknown foreign identifiers and cyclic aliases fail. Missing foreign keys remain missing. Every output table is independently shuffled so its original row order is not retained.

Retained CSV tokens are unchanged: exact VAS values, zeros, E/T, missing representations and actual-minute column names are preserved. No baseline VAS is created, no gap is interpolated, no event is recoded, and no derived statistic is recalculated. The former shapelet `source_subject` field was a positional array index, not a verified identifier; it was removed from the restricted copy rather than guessed into an identity link.

The completed local export covers the old baseline and ten old individual/shapelet tables, plus the latest 215-person baseline. The same private mapping accounts for the confirmed aliases. The legacy 216 rows remain 216 rows in that historical copy; they are not a new 216-person analysis. Every retained cell was independently compared, as a multiset after mapping, against its source. Individual records and mapping are in a restricted local directory outside this repository. Original files are retained byte-for-byte in the private pre-update backup.

The entire output directory is mode 0700; files are mode 0600. `manifest_PRIVATE.json` records input/output hashes, field lists, removed fields, confirmed-alias/policy hashes, exporter code hash, Git revision and software. `identity_mapping_PRIVATE.csv` must remain restricted and separate from any downstream sharing copy. Each export creates new IDs and refuses an existing output directory. To preserve links across a project, export all linked tables together; do not assume separate exports reuse IDs.

Exact age/body measures and pain trajectories remain quasi-identifiers. This process is pseudonymization and file hygiene, not proof of irreversible anonymity or permission to release individual records. See [history cleanup](history_cleanup.md) for the local cleanup and remote replacement procedure; the verified publication phase is recorded in `publication_status.json`.
