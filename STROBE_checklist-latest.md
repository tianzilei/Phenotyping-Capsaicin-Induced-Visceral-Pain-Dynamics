# STROBE Statement—checklist of items that should be included in reports of observational studies

This checklist has been updated to match the current manuscript package:

- Primary manuscript: `MANUSCRIPT.md`
- Narrative supplement: `supplementary_latest.md`

Where a reporting element is not yet finalized in the manuscript, the table notes that status explicitly.

| Item No | Recommendation | Current location in manuscript package |
|---------|----------------|----------------------------------------|
| **Title and abstract** | | |
| 1 | (a) Indicate the study's design with a commonly used term in the title or the abstract | `MANUSCRIPT.md`: Title page; Abstract, Methods |
| | (b) Provide in the abstract an informative and balanced summary of what was done and what was found | `MANUSCRIPT.md`: Abstract |
| **Introduction** | | |
| 2 | Explain the scientific background and rationale for the investigation being reported | `MANUSCRIPT.md`: Introduction, paragraphs 1-3 |
| 3 | State specific objectives, including any prespecified hypotheses | `MANUSCRIPT.md`: Introduction, paragraph 4 |
| **Methods** | | |
| 4 | Present key elements of study design early in the paper | `MANUSCRIPT.md`: Methods, "Ethics, registration, and reporting" and "Study design and participants" |
| 5 | Describe the setting, locations, and relevant dates, including periods of recruitment, exposure, follow-up, and data collection | `MANUSCRIPT.md`: Methods, "Study design and participants" and "Capsaicin administration" |
| 6 | (a) Cohort study—Give the eligibility criteria, and the sources and methods of selection of participants. Describe methods of follow-up | `MANUSCRIPT.md`: Methods, "Study design and participants"; Results, "Participant characteristics" |
| | (b) Cohort study—For matched studies, give matching criteria and number of exposed and unexposed | Not applicable |
| 7 | Clearly define all outcomes, exposures, predictors, potential confounders, and effect modifiers. Give diagnostic criteria, if applicable | `MANUSCRIPT.md`: Methods, "Capsaicin administration," "VAS numeric analysis," "Symptom, Rome IV, and network analyses," and "Prediction and classification"; `supplementary_latest.md`: S1-S3 |
| 8 | For each variable of interest, give sources of data and details of methods of assessment (measurement). Describe comparability of assessment methods if there is more than one group | `MANUSCRIPT.md`: Methods, "Study design and participants," "Capsaicin administration," "VAS numeric analysis," "Symptom, Rome IV, and network analyses," and "Prediction and classification"; `supplementary_latest.md`: S1-S3 |
| 9 | Describe any efforts to address potential sources of bias | `MANUSCRIPT.md`: Methods, "VAS numeric analysis" and "Prediction and classification"; Discussion, limitations paragraph; `supplementary_latest.md`: S10 |
| 10 | Explain how the study size was arrived at | `MANUSCRIPT.md`: Methods, "Study design and participants" and Results, "Participant characteristics". A formal sample size justification is not separately reported. |
| 11 | Explain how quantitative variables were handled in the analyses. If applicable, describe which groupings were chosen and why | `MANUSCRIPT.md`: Methods, "VAS numeric analysis," "Temporal clustering and shapelet analysis," "Symptom, Rome IV, and network analyses," and "Prediction and classification"; `supplementary_latest.md`: S1-S3 |
| 12 | (a) Describe all statistical methods, including those used to control for confounding | `MANUSCRIPT.md`: Methods, "VAS numeric analysis," "Temporal clustering and shapelet analysis," "Symptom, Rome IV, and network analyses," and "Prediction and classification"; `supplementary_latest.md`: S1-S3 |

| | (c) Explain how missing data were addressed | `MANUSCRIPT.md`: Methods, "VAS numeric analysis" and "Prediction and classification"; `supplementary_latest.md`: S1-S3 and S10 |
| | (d) Cohort study—If applicable, explain how loss to follow-up was addressed | `MANUSCRIPT.md`: Methods, "VAS numeric analysis"; Results, "Safety and adverse events"; `supplementary_latest.md`: S9-S10 |
| | (e) Describe any sensitivity analyses | Not separately reported |
| **Results** | | |
| 13 | (a) Report numbers of individuals at each stage of study—eg numbers potentially eligible, examined for eligibility, confirmed eligible, included in the study, completing follow-up, and analysed | `MANUSCRIPT.md`: Methods, "Study design and participants"; Results, "Participant characteristics". Screening-stage counts before the analytic cohort are not separately reported. |
| | (b) Give reasons for non-participation at each stage | `MANUSCRIPT.md`: Methods, "Study design and participants". Detailed screening-stage reasons are not separately reported. |
| | (c) Consider use of a flow diagram | Not included |
| 14 | (a) Give characteristics of study participants (eg demographic, clinical, social) and information on exposures and potential confounders | `MANUSCRIPT.md`: Results, "Participant characteristics" and Table 1 |
| | (b) Indicate number of participants with missing data for each variable of interest | `MANUSCRIPT.md`: Results, "Participant characteristics" notes core baseline completeness; censoring rules are described in Methods, "VAS numeric analysis". A full variable-by-variable missingness table is not separately reported. |
| | (c) Cohort study—Summarise follow-up time (eg, average and total amount) | `MANUSCRIPT.md`: Methods, "Study design and participants" and "Capsaicin administration"; Results, "Temporal VAS dynamics" |
| 15 | Cohort study—Report numbers of outcome events or summary measures over time | `MANUSCRIPT.md`: Results, "Temporal VAS dynamics," "Temporal phenotypes," "Symptoms, anatomical regions, and Rome IV-informed mapping," "Symptom-region network structure," "Prediction and classification," and "Safety and adverse events"; `supplementary_latest.md`: S4-S10 |
| 16 | (a) Give unadjusted estimates and, if applicable, confounder-adjusted estimates and their precision (eg, 95% confidence interval). Make clear which confounders were adjusted for and why they were included | `MANUSCRIPT.md`: Results, "Temporal VAS dynamics" and "Prediction and classification"; `supplementary_latest.md`: S4-S10. Confounder-adjusted regression estimates are not a main feature of this analysis. |
| | (b) Report category boundaries when continuous variables were categorized | `MANUSCRIPT.md`: Methods, "VAS numeric analysis" and "Symptom, Rome IV, and network analyses"; Results, "Symptoms, anatomical regions, and Rome IV-informed mapping" |
| | (c) If relevant, consider translating estimates of relative risk into absolute risk for a meaningful time period | Not applicable |
| 17 | Report other analyses done—eg analyses of subgroups and interactions, and sensitivity analyses | `MANUSCRIPT.md`: Results, "Prediction and classification"; `supplementary_latest.md`: S4-S10. Sensitivity analyses are not separately reported. |
| **Discussion** | | |
| 18 | Summarise key results with reference to study objectives | `MANUSCRIPT.md`: Discussion, first paragraph |
| 19 | Discuss limitations of the study, taking into account sources of potential bias or imprecision. Discuss both direction and magnitude of any potential bias | `MANUSCRIPT.md`: Discussion, limitations paragraph |
| 20 | Give a cautious overall interpretation of results considering objectives, limitations, multiplicity of analyses, results from similar studies, and other relevant evidence | `MANUSCRIPT.md`: Discussion, paragraphs 2-7; `supplementary_latest.md`: S10 |
| 21 | Discuss the generalisability (external validity) of the study results | `MANUSCRIPT.md`: Discussion, limitations paragraph and final paragraph |
| **Other information** | | |
| 22 | Give the source of funding and the role of the funders for the present study and, if applicable, for the original study on which this present article is based | `MANUSCRIPT.md`: Title page, "Financial support" and Author disclosures, "Funding". Both are still marked "To be completed before submission." |

*Give information separately for cases and controls in case-control studies and, if applicable, for exposed and unexposed groups in cohort and cross-sectional studies.

**Note:** This checklist is aligned to the current markdown manuscript set rather than to page numbers in a formatted PDF. If the paper is typeset for submission, the rightmost column can be converted from section references to final page numbers.
